# Hedstok

**Acquisition intelligence for used musical instruments.**

Hedstok explores whether software can discover interesting acquisition opportunities that conventional search would not necessarily surface.

The project focuses on messy listings, private leads, incomplete information, provenance, uncertainty, and explainable analysis.

> **Evidence before assumptions. Discovery before search.**

## Status

🚧 **Early R&D / First Working Pipeline**

Hedstok is an early-stage acquisition-intelligence experiment.

The project now has a working evidence pipeline that can process multiple used-instrument listings and produce structured, source-grounded evidence while preserving uncertainty and the distinction between source claims and established facts.

The initial experiments established the extraction model and evaluation approach. Phase 2 demonstrated that the pipeline can process a collection of listings, preserve source evidence, identify mechanical extraction failures, and support human semantic evaluation.

The architecture and feature set remain exploratory. Further capabilities will be developed experimentally rather than assumed in advance.

## Core Question

> Can software discover interesting acquisition opportunities that a conventional search would not necessarily surface?
